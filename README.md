# Лабораторна робота № 1. Розгортання середовища автоматизації тестування

Дисципліна: Автоматизація тестування
Виконала: Чорней Василина Павлівна, група ІПЗ 4
Варіант: 10 (обчислення простих відсотків)

## Структура проєкту

```
qa-automation/
├── src/
│   ├── temperature.ts        # приклад із показової частини
│   └── simple-interest.ts    # модуль індивідуального завдання (варіант 10)
├── tests/
│   ├── temperature.test.ts
│   └── simple-interest.test.ts
├── .gitignore
├── .prettierrc
├── eslint.config.mjs
├── package.json
├── tsconfig.json
├── vitest.config.ts
└── README.md
```

## Встановлення

Потрібні Node.js 20+ і npm.

```bash
npm install
```

## Запуск

| Команда              | Призначення                                                    |
| -------------------- | -------------------------------------------------------------- |
| `npm test`           | одноразовий прогін тестів                                      |
| `npm run test:watch` | режим спостереження                                            |
| `npm run coverage`   | прогін із вимірюванням покриття (звіт у `coverage/index.html`) |
| `npm run lint`       | статичний аналіз коду                                          |
| `npm run format`     | форматування коду                                              |
